# 2026-08-31

## 服务器配置合并策略改造（B服 value 更新）

- 需求：默认配置 B服01/B服02 的 value 从 `bilibili01/bilibili02` 改为 `bb01/bb02`（旧标识已失效）；老用户配置（version 旧、B服 value 还是旧值）合并时不能出现两个 B服01/B服02。
- 根因：`mergeConfigs` 旧逻辑**按 value 去重**，name 相同但 value 不同（bilibili01 vs bb01）会被当两个服务器保留 → 用户看到两个 B服01。
- 修复（electron/utils/index.ts）：`mergeConfigs` 重写为**按名称匹配**——名称与默认配置一致的采用新版默认（value 同步更新），名称是用户自定义的保留，默认配置缺的补全；display=false（用户隐藏）仍尊重。删除了不再使用的 `compareVersions`。
- 验证：node 模拟三个场景全通过（老配置迁移、自定义保留、隐藏状态保留、空配置）；vue-tsc 0 错误。
- 提醒：value 变更后，老用户首页若仍选中 B服01，localStorage 里的 serverName 是旧值 bilibili01，需重新选择一次（新版启动后合并配置会自动把下拉项更新为 bb01）。

## 首页服务器下拉兜底（旧值失效默认选第一个）

- 现象：老用户 serverName 存的是旧值 bilibili01，新列表里没有该项，el-select 直接显示原始 value 文本。
- 修复（home/index.vue `receiveServerData`）：当前值**不在**服务器列表中时（含空），自动选中第一项并写入 localStorage（`serverList.value[0]?.value || ''`，兼容空列表）。vue-tsc 通过。
