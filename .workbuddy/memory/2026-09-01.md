## 修复：主题切换/自定义颜色不生效

- 根因1：base.css 的 `--color-background` 系列只跟随 `@media (prefers-color-scheme)`，**不跟随 html.dark**——设置页切深色时 element-plus 组件变了但 footer/列表/map-box 等自定义背景不变。
- 根因2：之前加的 `--app-bg` 变量在 base.css 中已不存在（被外部改动覆盖），settings.ts 设置 --app-bg 无效。
- 修复：base.css 末尾加 `html.dark { --color-background 系列深色值 }`；settings.ts applyColors 改为覆盖 `--el-color-primary` 全套 + `--brand-color` + `--color-background/-soft/-mute`（背景色同色覆盖，清除时 removeProperty）。
- 构建环境备忘：vite build 被 safe-delete shim 拦时（rmSync dist-electron / emptyDir dist），先 PowerShell `Remove-Item` 删 dist 与 dist-electron（一次可能不彻底，必要时重试），两目录不存在后再 build 一次跑通。

## 空状态引导改为仅首次安装显示

- 需求：引导只在第一次安装后首次进入 typeIn 页显示，后续（空状态、更新版本）都不显示。
- 实现：localStorage 标记 `typeInGuideSeen`；`guideSeen` ref 初始化读标记；模板 v-if 加 `&& !guideSeen`；onMounted 里首次进入即写标记（渲染后执行，保证本次仍显示，之后不再显示）。vue-tsc 通过。
